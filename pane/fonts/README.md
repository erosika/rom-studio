# The pane's typefaces

The two faces of ROM Studio's look (the same as its video): IBM Plex Mono for the name, tabs, labels and captions,
Inter for longer text. Inside Hermes, longer text takes Hermes's own face instead; Plex Mono stays.

| `Inter_18pt-Regular.ttf`, `Inter_18pt-SemiBold.ttf` | Inter (static, 18 pt optical size) | SIL Open Font License 1.1 (`LICENSE-Inter.txt`) | github.com/rsms/inter, the Google Fonts download's `static/` folder |
