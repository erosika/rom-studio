Save point

save here keeps this exact moment and load goes back to it. A save point fits only the build of the game it was made on: after the game is rebuilt it cannot be loaded.

The game's own save

Saving inside the game (START, then SAVE) is the save that lasts: it carries on after the game is rebuilt and after this page is closed. Choose CONTINUE on the title screen.

Both are kept in this browser on this device, for this game. Export gives you a file to keep or to open on another device; import puts one back.
